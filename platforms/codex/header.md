# Obsidian Personal Knowledge Base

> **Compatibility adapter:** Legacy/manual integrations only. New Codex installs use the user-level skill `skills/obsidian-knowledge-base/SKILL.md`.

Installed compatibility resources live at `~/.obsidian-kb-skill/skill`; use that directory as `<skill-root>` for references, assets, and bundled helpers.

**Trigger**: Use on explicit save intent ("save to Obsidian", "沉淀", "记一下"), a personal todo or memo （记个待办、备忘一下、勾掉、改到、取消）, or an explicit request to evaluate what from a conversation is worth capturing. Listing （列一下我现在的代办、列一下备忘） belongs to retrieval. Harvest analysis may be read-only; never mutate the Vault without save intent. Never use for unrelated Q&A/debug/chat.
