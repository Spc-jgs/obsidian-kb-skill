# Standard Agent Skill Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 v1.7.0，以 `skills/obsidian-knowledge-base/SKILL.md` 作为平台无关的标准 Skill 入口，并让 Codex、QoderWork 和本机共享安装使用它。

**Architecture:** `core/OBSIDIAN_KB.md` 继续是正文唯一来源，`build.py` 使用显式 header/output 路径生成标准 Skill 和四个平台兼容产物。安装器把标准 Skill 复制到各平台发现目录；旧适配产物保留但不再作为 Codex、QoderWork 的安装来源。

**Tech Stack:** Python 3.9、pytest、Bash、PowerShell、Markdown、GitHub CLI

## Global Constraints

- 标准入口固定为 `skills/obsidian-knowledge-base/SKILL.md`。
- 标准 Skill 必须由 `build.py` 生成，禁止维护第二份手写正文。
- `platforms/qoderwork/SKILL.md` 和 `platforms/codex/AGENTS.md` 必须继续生成。
- Codex 用户级安装位置固定为 `$HOME/.agents/skills/obsidian-knowledge-base/SKILL.md`。
- QoderWork 目标位置不变，但安装来源必须改为标准 Skill。
- Claude Code、Cursor、Vault 内容工作流和 Folder Index 行为不得改变。
- Bash 与 PowerShell 安装、卸载语义必须对等。
- 版本号固定升级为 `1.7.0`。

- [ ] **Step 3: 实现显式构建目标**

在 `build.py` 中新增：

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class BuildTarget:
    name: str
    header: Path
    output: Path


TARGETS = [
    BuildTarget(
        "standard-agent-skill",
        ROOT / "skills" / "obsidian-knowledge-base" / "header.md",
        ROOT / "skills" / "obsidian-knowledge-base" / "SKILL.md",
    ),
    BuildTarget("qoderwork", ROOT / "platforms/qoderwork/header.md", ROOT / "platforms/qoderwork/SKILL.md"),
    BuildTarget("claude-code", ROOT / "platforms/claude-code/header.md", ROOT / "platforms/claude-code/CLAUDE.md"),
    BuildTarget("codex", ROOT / "platforms/codex/header.md", ROOT / "platforms/codex/AGENTS.md"),
    BuildTarget("cursor", ROOT / "platforms/cursor/header.md", ROOT / "platforms/cursor/obsidian-kb.mdc"),
]
```

修改生成注释，让它接收相对 header 路径：

```python
def build_adapter(header: str, body: str, header_path: str) -> str:
    banner = (
        "<!-- AUTO-GENERATED by build.py from core/OBSIDIAN_KB.md + "
        f"{header_path}. DO NOT EDIT DIRECTLY. -->\n\n"
    )
```

循环统一使用 `target.header`、`target.output` 和
`target.header.relative_to(ROOT).as_posix()`。

def test_bash_installer_uses_standard_skill_for_codex(tmp_path):
    vault, home = run_bash_installer(tmp_path, platforms="codex")
